# LeetCode Solutions

[![License: MIT](https://img.shields.io/badge/license-MIT-green)](LICENSE)

A collection of my solutions to [LeetCode](https://leetcode.com/u/PNRIVA/) problems.

This repository is automatically updated with my submitted solutions and serves as a record of my progress in data structures, algorithms, and problem solving.

## Structure

Solutions are organized by **programming language**, **difficulty**, and **problem**:

```text
Language/
├── Easy/
│   └── problem/
├── Medium/
│   └── problem/
└── Hard/
    └── problem/
```

When I find different approaches to the same problem, multiple solutions may be included in its directory.
